# MJM Leads

CRM ligero de prospección para **MJM Systems**.

## V1

- Dashboard responsive estilo app.
- Scoring de leads de 1 a 100.
- Clasificación por oportunidad: web/catálogo, inventario/POS, automatización/CRM y sistema a medida.
- Pipeline: Nuevo → Contactado → Interesado → Reunión → Ganado/Perdido.
- Filtros por distrito, oportunidad y estado.
- Alta, edición y eliminación de prospectos.
- Persistencia local con `localStorage`.
- Acceso directo a WhatsApp y web cuando existe un dato cargado.

## Publicación

Es una web estática. Puedes desplegarla directamente con **Vercel** importando este repositorio, o con GitHub Pages.

## Importante

Los registros incluidos inicialmente son únicamente datos demo para probar el producto. Los datos de prospectos reales deben obtenerse de fuentes públicas y verificarse antes de contactar.

## Siguiente evolución recomendada

1. Integración con una fuente de negocios real (por ejemplo Google Places u otra fuente autorizada).
2. Enriquecimiento de teléfonos, webs y redes sociales públicas.
3. Scoring automático basado en señales comerciales reales.
4. Plantillas personalizadas de primer contacto.
5. Seguimientos y recordatorios.
6. Exportación CSV/Sheets.
7. Backend para sincronizar leads entre dispositivos.
